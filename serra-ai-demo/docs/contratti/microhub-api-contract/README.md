# Pacchetto API Micro-Hub CEA

File inclusi:

- `openapi.yaml`: specifica OpenAPI 3.1 draft del backend che dovrà alimentare il frontend.
- `FRONTEND_BACKEND_INTEGRATION.md`: mappa schermate/API, convenzioni dei dati, flussi asincroni, SSE, gestione errori e criteri di accettazione.

Il contratto è proposto in base alle funzionalità descritte nel progetto. Non è stato estratto dal codice React, che deve essere ispezionato da Claude Code prima dell'implementazione.

Modalità prevista per questa prima versione: `SIMULATION`. Nessun comando diretto verso hardware fisico è esposto.
